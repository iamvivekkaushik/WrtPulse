# Mesh Deployment Checklist

## قبل التنفيذ
- [ ] تحديد طراز كل جهاز وإصدار OpenWrt.
- [ ] تحديد نوع الربط: 802.11s أو BATMAN-ADV أو WDS أو AP متعدد النقاط.
- [ ] رسم الطوبولوجيا وتحديد backhaul لكل عقدة.
- [ ] التحقق من دعم الشريحة والتعريف والـ firmware.
- [ ] تحديد القنوات وعرضها وفق البيئة والأنظمة المحلية.
- [ ] تحديد خطة عناوين IP وDHCP وDNS وVLAN.
- [ ] حفظ نسخة احتياطية من `/etc/config`.
- [ ] توفير اتصال محلي/سلكي أو خطة رجوع.

## بعد التنفيذ
- [ ] اختبار اتصال كل عقدة بالبوابة.
- [ ] اختبار ping وفقد الحزم وزمن الاستجابة بين العقد.
- [ ] اختبار DHCP وDNS من كل نقطة.
- [ ] قياس throughput لكل قفزة ومقارنته بالـ backhaul.
- [ ] فحص roaming بين نقاط الوصول.
- [ ] مراقبة السجلات وإعادة الاتصال تحت الحمل.
- [ ] التأكد من عدم وجود حلقات Layer 2.

## تنبيه
هذا الملف قائمة تحقق فقط. لا تنفذ تغييرات الشبكة أو إعادة تشغيل الخدمات تلقائياً.
