# OpenWrt Mesh Networking

## الهدف
تشخيص وتصميم شبكات Mesh في OpenWrt مع دعم:
- IEEE 802.11s (Mesh Point)
- BATMAN-ADV
- WDS (Wireless Distribution System)
- بنية Access Point متعددة النقاط مع تجوال العملاء (AP roaming)

## قواعد أساسية
1. ابدأ بجمع المعلومات قبل أي تغيير.
2. لا تفترض أن كل الأجهزة أو تعريفات Wi-Fi تدعم 802.11s أو WDS.
3. لا تخلط بين 802.11s وBATMAN-ADV: الأول طبقة ربط لاسلكية، والثاني بروتوكول توجيه طبقة ثانية يمكن أن يعمل فوق واجهات مناسبة.
4. شبكة AP متعددة النقاط مع 802.11r/k/v ليست بالضرورة Mesh لاسلكياً؛ قد تستخدم backhaul سلكياً.
5. لا تطبق إعدادات أو تعِد تشغيل الشبكة قبل موافقة المستخدم ووجود وسيلة وصول بديلة.
6. احتفظ بنسخة احتياطية من `/etc/config` قبل أي تغيير.

## اكتشاف النوع
- افحص إصدار OpenWrt: `ubus call system board`
- افحص الواجهات اللاسلكية: `iw dev`
- افحص قدرات الراديو: `iw phy`
- افحص الحزم: `opkg list-installed` أو `apk list --installed` بحسب الإصدار.
- افحص الوحدات: `lsmod | grep -E 'batman|cfg80211|mac80211'`
- افحص حالة batman: `batctl meshif bat0 originators` إذا كان batctl موجوداً.
- افحص إعدادات الشبكة واللاسلكي دون نشر كلمات المرور أو مفاتيح التشفير.

## منهج التشخيص
1. تحديد الطوبولوجيا: عقدة رئيسية، عقد فرعية، backhaul سلكي/لاسلكي.
2. تحديد الطبقة المستخدمة: 802.11s أو WDS أو BATMAN-ADV أو AP roaming.
3. فحص القناة وعرضها والتداخل وقوة الإشارة ووقت الهواء.
4. فحص MTU وbridging وVLAN وDHCP وDNS والتوجيه.
5. فحص فقد الحزم وزمن الاستجابة بين كل عقدة والبوابة.
6. تقديم تقرير مع السبب المرجح وخطوات إصلاح مقترحة، دون تنفيذها تلقائياً.

## مؤشرات مهمة
- RSSI وحده لا يكفي؛ راقب معدل الإرسال/الاستقبال وإعادة المحاولات.
- قناة backhaul مزدحمة أو ضعيفة قد تخفض أداء الشبكة كلها.
- تعدد القفزات اللاسلكية يستهلك وقت الهواء ويزيد التأخير.
- تجنب حلقات Layer 2؛ تحقق من تصميم الجسر وSTP عند الحاجة.
- لا تستخدم نفس القناة تلقائياً لكل الراديوهات دون دراسة التداخل والطوبولوجيا.

## مخرجات التقرير
- نوع الشبكة المكتشف ودرجة الثقة.
- قائمة العقد والواجهات المرئية.
- جودة الروابط ومعدلات النقل وإعادة المحاولات.
- حالة BATMAN-ADV إن وجد.
- حالة DHCP/DNS والبوابة.
- المشكلات المحتملة والتوصيات مرتبة حسب الأولوية.
