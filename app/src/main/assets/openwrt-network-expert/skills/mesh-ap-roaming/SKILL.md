# Multi-AP and Client Roaming

## التمييز
شبكة عدة نقاط وصول قد تستخدم backhaul سلكياً أو لاسلكياً. التجوال بين نقاط الوصول يعتمد على العميل وإعدادات الشبكة؛ 802.11k/v/r قد يحسن التجربة لكنه لا يضمن انتقالاً سلساً لكل الأجهزة.

## فحوصات
```sh
iw dev
iw dev <ap-interface> station dump
ubus call hostapd.<interface> get_clients
logread | grep -Ei 'hostapd|wpa|roam|disassoc|auth'
```

## تحسينات التصميم
- استخدم SSID وأماناً متوافقين عبر نقاط الوصول التابعة للشبكة نفسها.
- فضّل backhaul سلكياً عند توفره.
- خطط القنوات لتقليل التداخل بين نقاط الوصول المتجاورة.
- لا تفعّل 802.11r قبل اختبار توافق أجهزة العملاء.
- اضبط قدرة الإرسال بناءً على القياس، لا على أعلى قيمة متاحة.
- راقب sticky clients وعمليات إعادة المصادقة وفقد الحزم.

## التشخيص
قارن RSSI ووقت الانتقال وأحداث association/disassociation، وافحص إن كانت المشكلة من العميل أم نقطة الوصول أم backhaul.
