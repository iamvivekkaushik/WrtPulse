# السلامة والخصوصية

- هذه الحزمة تجمع معلومات ولا تعدّل إعدادات الراوتر.
- لا تشغّل أوامر `uci set`, `uci commit`, `wifi reload` أو إعادة تشغيل الشبكة دون موافقة صريحة.
- احتفظ بنسخة إعدادات قبل أي تغيير.
- قد تحتوي المخرجات على SSID وعناوين IP وMAC وأسماء الأجهزة؛ احذفها قبل النشر.
- لا ترسل ملفات `/etc/config/wireless` أو النسخ الاحتياطية دون تنقيح الأسرار.
- الاختبارات المتكررة أو الكثيفة قد تؤثر في الشبكة؛ استخدم عدد حزم محدوداً.
