# Interference Analysis

## الهدف
تحليل ازدحام الطيف المرئي وتداخل القنوات دون الادعاء بأن مسح Wi-Fi يقيس كل مصادر التداخل اللاسلكي.

## جمع البيانات
- `iwinfo <iface> scan`
- `iwinfo <iface> info`
- `iwinfo <iface> assoclist`
- `iw dev <iface> survey dump` إذا كان تعريف الجهاز يدعم survey statistics.
- `logread` لمراجعة تغيّر القناة أو انقطاعات الراديو.

## التحليل
1. اجمع نتائج المسح مرتين أو ثلاثاً في أوقات مختلفة؛ نتائج المسح لقطة زمنية وقد لا تمثل الحمل الفعلي.
2. صنّف الشبكات حسب النطاق والقناة وعرض القناة وقوة الإشارة.
3. في 2.4GHz، انتبه إلى تداخل القنوات المتجاورة؛ لا تقارن رقم القناة وحده.
4. في 5GHz، احسب تداخل القنوات وفق عرض القناة الفعلي وقيود DFS.
5. فرّق بين:
   - co-channel contention: أجهزة تشارك القناة نفسها وتتقاسم وقت البث.
   - adjacent-channel interference: تداخل قنوات متجاورة/متداخلة.
   - non-Wi-Fi interference: لا يمكن إثباته من قائمة شبكات Wi-Fi وحدها.
6. لا تعتبر عدد نقاط الوصول وحده مقياساً كافياً؛ قوة الإشارة وعرض القناة والحمل أهم أيضاً.

## المخرجات
قدّم جدولاً يتضمن القناة، عرض القناة، عدد الشبكات المرئية، أقوى RSSI، وملاحظات التداخل.
اذكر بوضوح أن هذا تحليل للشبكات المرئية وليس محللاً طيفياً RF حقيقياً.

## السلامة
لا تغيّر القناة أو عرضها تلقائياً. اعرض خيارين مع أثر متوقع وخطة رجوع واطلب الموافقة.
