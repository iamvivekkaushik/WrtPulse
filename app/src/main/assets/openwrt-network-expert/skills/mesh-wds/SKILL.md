# WDS

## المفهوم
WDS يربط نقاط وصول لاسلكياً، لكن تفاصيل التوافق تختلف حسب الشريحة والتعريف ووضع التشغيل. لا تعتبر WDS معياراً موحد التنفيذ بين جميع المصنعين.

## فحوصات
```sh
iw dev
iw list
iw dev <interface> station dump
iw dev <interface> link
logread | grep -Ei 'wds|hostapd|wpa|wireless'
```

## نقاط التحقق
- دعم WDS في التعريف ووضع AP/STA.
- توافق إعدادات الأمان بين الطرفين.
- توافق القناة وعرضها والمنطقة التنظيمية.
- وجود واجهات WDS ضمن الجسر الصحيح.
- عدم وجود DHCP servers متنافسة أو حلقات Layer 2.

## ملاحظة
تحقق من إعدادات الجهازين قبل تعديل أي خيار WDS؛ قد تختلف أسماء الخيارات بين إصدارات OpenWrt وتعريفات الأجهزة.
