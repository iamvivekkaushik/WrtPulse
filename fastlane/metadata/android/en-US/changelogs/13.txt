• AI analysis: a real diagnostic tool, in three read-only layers. A network health score (Wi-Fi, Mesh, Performance, Security subscores) computed on the phone. A 60-second, three-sample performance window that differences tx retries, tx failed, packet loss, latency, CPU, RAM and per-interface throughput — so a weak mesh link is proven with numbers, not suspected. Local rules find the obvious problems offline before any AI is asked: weak signal below -80 dBm, climbing tx failed, a full /overlay, rogue DHCP scopes, bridges without STP, wpad packages that cannot run 802.11s, an internet path broken before or after the first hop — each finding shown with its evidence, the exact command behind it and the raw data. Six ready-made analyses (Wi-Fi, Mesh & WDS, Performance, Security, Internet outage, DHCP/bridge/STP) aim the provider at one subsystem. Ollama on your own LAN now works as a provider with no API key — the analysis never leaves your network. Commands in the answer are guarded: read-only ones copy in one tap, changing ones ask for a second confirming tap, and destructive ones (reboot, firstboot, sysupgrade) are never offered for copying. The whole analysis exports as Markdown, plain text or PDF, with an option to hide MAC and public addresses before sharing. The provider's model field is now a dropdown that fills by itself: the list comes from the provider's own /models endpoint (OpenAI, OpenRouter, Gemini, Groq, an Ollama server, any compatible gateway) as soon as the base URL and key are set, filters to what you type, and still takes a hand-typed id when a provider lists none. OpenRouter joins the presets — one key, every model behind it, with openrouter/auto as the default.
