# Advanced Channel Planning

## المدخلات المطلوبة
- البلد/النطاق التنظيمي المضبوط على الجهاز.
- موديل الراوتر والشريحة وتعريفها.
- نطاق الراديو: 2.4 أو 5 أو 6GHz.
- نتائج scan مع القنوات وعروضها وRSSI.
- متطلبات العملاء: التوافق، المدى، throughput، الاستقرار.

## طريقة التوصية
1. اقرأ `iwinfo` و`iw list` إن توفر لمعرفة القدرات والقنوات المدعومة.
2. تحقق من country code وإعدادات regulatory domain؛ لا تستنتج البلد من الموقع الجغرافي وحده.
3. استبعد القنوات المحظورة أو غير المتاحة حسب البلد والجهاز.
4. 2.4GHz: ابدأ بمقارنة 1/6/11 فقط حيث تكون مسموحة، وغالباً بعرض 20MHz. لا تفترض أنها الوحيدة المسموحة في كل البلدان.
5. 5GHz: راعِ DFS، واحتمال تأخر بدء البث أو تبديل القناة عند رصد الرادار.
6. 6GHz: لا توصي به إلا إذا كان الجهاز والعملاء والنظام التنظيمي يدعمونه.
7. قيّم 20/40/80/160MHz وفق الازدحام والقدرة الفعلية؛ العرض الأكبر قد يقلل الاستقرار في بيئة مزدحمة.
8. أخرج التوصية بصيغة: الخيار الأفضل، البديل، سبب الاختيار، المخاطر، وما الذي يجب قياسه بعد التغيير.

## لا تفعل
- لا تضبط country code لتجاوز القيود.
- لا ترفع TX power فوق الحدود المحلية.
- لا تطبق `uci set` أو `wifi reload` دون موافقة صريحة.
